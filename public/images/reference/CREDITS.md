# Reference photograph credits — DEMO ONLY

Every file in this folder is a **licensed stock photograph used as temporary,
decorative reference imagery**. None of these is a Kalimeris vehicle, none is
client inventory, and none may be presented as an actual available rental.
Replace each one with client-owned or client-authorised photography before any
production launch.

All files were fetched by `scripts/fetch-reference-photos.mjs` and verified as
real JPEG files larger than 20 KB.

## Rules for using these files

- Always show a visible `DEMO` badge when a reference photograph is mapped to a
  vehicle card or a vehicle detail page.
- Never use these images as the client's own fleet, staff, premises or reviews.
- Keep this file in sync with whatever ships in `public/images/`.
